## 1. 機能概要

ユーザーのプロフィール情報を表示・編集する機能。
プロフィール画面（公開）では投稿一覧・フォロワー/フォロー中数を確認できる。
訪問済み・行きたいリストはマイページ（非公開）で管理する。
プロフィール画像は AWS S3 に保存する（実装計画書 Phase 6-A で対応済み）。

---

## 2. ユーザーストーリー

| ID | ストーリー |
|----|-----------|
| US-01 | ユーザーとして、他ユーザーのプロフィール（ニックネーム・アイコン・自己紹介・投稿一覧）を確認したい |
| US-02 | ユーザーとして、自分のニックネーム・自己紹介を編集したい |
| US-03 | ユーザーとして、プロフィール画像をアップロード・変更したい |
| US-04 | ユーザーとして、マイページで自分の訪問済み / 行きたいリストを確認したい |
| US-05 | ユーザーとして、プロフィール画面でフォロワー数・フォロー中数を確認したい |
| US-06 | ユーザーとして、自分が投稿したコメントを一覧で確認したい |
| US-07 | ユーザーとして、自分の投稿に届いたコメントを一覧で確認したい（自分のみ閲覧可） |

## 3. 機能詳細

### 3.1 プロフィール表示

- URL：`/users/[id]`
- 表示情報：
  - プロフィール画像（未設定時はデフォルトアイコン）
  - ニックネーム（nickname）
  - 自己紹介（bio）
  - TabiScore（旅スコア・ランク）
  - 投稿数 / フォロワー数 / フォロー中数
  - フォローボタン（自分以外のユーザーに表示）
  - 投稿一覧タブ
  - 投稿したコメントタブ（対象ユーザーが書いたコメントの一覧。2026-07-30更新：`GET /api/users/[id]/comments`によるcursorページング）
  - 自分へのコメントタブ（**本人閲覧時のみ表示**：自分の投稿に届いたコメント一覧。2026-07-30更新：`GET /api/users/[id]/comments-received`によるcursorページング、本人限定）
  - フォロワー一覧タブ（2026-07-30更新：`GET /api/users/[id]/followers`によるcursorページング）
  - フォロー中一覧タブ（2026-07-30更新：`GET /api/users/[id]/following`によるcursorページング）
- 行きたい・訪問済みのカウントはプロフィール画面に表示しない（マイページで管理）
- 継続取得（2026-07-30追加、GATE-22種類B）：上記4タブはいずれも初回20件を表示し、一覧末尾の「もっと見る」ボタンで追加取得する。フォロワー・フォロー中タブは追加取得時も各ユーザーのフォロー状態（`followedByCurrentUser`）をAPIレスポンスに含めるため、フォローボタンの表示が正しく機能する

### 3.2 TabiScore（旅スコア）

ユーザーの旅行活動量を数値化したスコア。プロフィール画面に表示する。

**計算式**

```
TabiScore = 投稿数 × 10 + 訪問済み数 × 5 + 受けたいいね数 × 3 + 受けたコメント数 × 2
```

**ランク判定**

| スコア | ランク |
|-------|-------|
| 100 以上 | プラチナトラベラー |
| 60〜99 | ゴールドトラベラー |
| 30〜59 | シルバートラベラー |
| 0〜29 | ブロンズトラベラー |

- スコアとランクはリアルタイム集計（保存しない）
- プロフィール画面のヘッダーにバッジ形式で表示する

---

### 3.3 プロフィール編集

- URL：`/settings`（タイトル: ✏️ プロフィール編集）
- 自分のプロフィールのみ編集可能
- 編集可能項目：ニックネーム（nickname）・自己紹介（bio）
- 画面右上に「🔐 アカウント設定」リンクを設置し、`/settings/account`（メールアドレス変更・パスワード変更）へ遷移できる（2026-07-09追加。メールアドレスは本画面には表示しない。詳細は `認証機能定義書.md` 3.4節を参照）
- キャンセルボタンで保存せず公開プロフィール画面へ戻る
- `PUT /api/users/[id]` で更新する（`updatedAt`必須。編集画面表示時点の値を送信し、他のリクエストが先に更新済み（`updatedAt`不一致）の場合は409エラーになる。フロントは「他の画面で更新されています。再読み込みしてください。」とエラー表示する。実装当初は対象外としていたが、S3を伴うアバター削除の安全性のため投稿編集と同様の楽観ロックを追加した）
  - **既知の制限**：`User.updatedAt`はパスワード変更・メールアドレス変更（`/settings/account`）でも更新されるため、他画面でパスワード/メールを変更した直後にプロフィール（画像とは無関係な項目）を保存すると、実際には競合していなくても409になることがある。安全側に倒した設計上のトレードオフとして受容する
- 保存成功後：トーストメッセージを表示し、自分の公開プロフィール画面へ遷移する

### 3.4 プロフィール画像アップロード

- 設定画面（`/settings`）から画像を選択してアップロードする
- `POST /api/upload/avatar` でS3にアップロードしURLを取得（既存の `upload/post` と同じ `saveUploadedFile()` を共有。キーは `uploads/{ownerUserId}/{uuid}.{ext}`）
- `PUT /api/users/[id]` で `image` URL を更新する。設定できるのは自分がアップロードしたS3オブジェクト・`null`（削除）・変更前と同じURLのいずれかのみ
- 対応フォーマット：JPEG / PNG / WebP（`upload/post` と異なりGIFは対象外）
- 最大サイズ：5MB（`upload/post` の10MBより厳しく設定）
- 更新成功後、旧画像と異なるS3オブジェクトが設定された場合は旧オブジェクトをベストエフォートで削除する

## 4. 使用 API

| Method | エンドポイント | 説明 | 認証 |
|--------|--------------|------|------|
| GET | `/api/users/[id]` | ユーザー情報取得 | 不要 |
| GET | `/api/users/[id]/comments` | 投稿したコメント一覧を継続取得（`cursor`/`limit`対応。2026-07-30新設） | 不要 |
| GET | `/api/users/[id]/comments-received` | 自分の投稿に届いたコメント一覧を継続取得（`cursor`/`limit`対応。2026-07-30新設） | 必要（本人のみ） |
| GET | `/api/users/[id]/followers` | フォロワー一覧を継続取得（`cursor`/`limit`対応。2026-07-30新設） | 不要 |
| GET | `/api/users/[id]/following` | フォロー中一覧を継続取得（`cursor`/`limit`対応。2026-07-30新設） | 不要 |
| PUT | `/api/users/[id]` | プロフィール編集（`updatedAt`必須。不一致時は409） | 必要（本人のみ） |
| POST | `/api/upload/avatar` | プロフィール画像をアップロード（S3保存、5MB・jpeg/png/webpのみ） | 必要 |

**レスポンス例（ユーザー情報）**

```json
{
  "id": "cm_xxx",
  "nickname": "田中花子",
  "image": "https://s3.ap-northeast-1.amazonaws.com/tripdiary/...",
  "bio": "旅が好きです",
  "postCount": 25,
  "followerCount": 12,
  "followingCount": 8,
  "followedByCurrentUser": true,
  "tabiScore": 120,
  "tabiRank": "ゴールドトラベラー"
}
```
> `email` は含まない（プロフィールは他ユーザーにも公開されるため非公開情報として除外）。

## 5. バリデーション仕様

| 項目 | フロントエンド | バックエンド |
|------|-------------|------------|
| ニックネーム（nickname） | 必須・1〜20文字・文字数カウンター表示 | 必須・1〜20文字 |
| 自己紹介（bio） | 任意・最大200文字・文字数カウンター表示 | 任意・最大200文字 |
| プロフィール画像 | 任意・フォーマットチェック | 任意・MIME タイプ・サイズ検証 |
| 他人のプロフィール編集 | - | 403 を返す |

---

## 6. 制約・前提条件

- プロフィール編集・画像アップロードはログインユーザーのみ、かつ本人のみ可能
- プロフィール表示（`/users/[id]`）は未認証ユーザーも閲覧可能
- プロフィール画像の最大サイズは5MB（3.4節参照）

---

## 7. 対象外仕様

| 機能 | 理由 |
|------|------|
| ユーザー名（@nickname）の設定 | スコープ外（name のみ管理） |
| アカウント削除 | スコープ外 |
| メールアドレス変更 | `/settings/account`（アカウント設定）で提供。認証機能定義書 3.4節参照 |
| パスワード変更 | `/settings/account`（アカウント設定）で提供。認証機能定義書 3.4節参照 |
